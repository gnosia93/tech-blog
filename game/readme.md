쓸 때마다 **"이 블로그로 어떤 고객과 어떤 대화를 시작할 수 있는가"**를 함께 정해 두면, 블로그가 콘텐츠로 끝나지 않고 파이프라인 도구가 됩니다.

원하시면 이 중 하나를 골라 PPS 편처럼 블로그 본문과 측정 스크립트, CloudFormation을 game-pps와 같은 구조로 만들어 드리겠습니다. 2편(CPU 지터)이라면 기존 키트를 확장하는 방식으로 진행할 수 있습니다.
